# Portafolio de dashboards · Nyxum

Portafolio de evidencias del curso **Digital Business Intelligence: gobernanza práctica con herramientas y dashboards** (Specialization in AI for Digital Business, INCAE Business School, 2026).

Autor: Luis Alfredo Leiva Artavia. Empresa analizada: [Nyxum](https://www.nyx-um.com/).

Sitio publicado: https://lleivaa23.github.io/nyxum-dbi-portafolio/

- `index.html`: portada, introducción, justificación y audiencia.
- `empresa.html`: perfil de Nyxum, objetivos estratégicos y dominios de datos.
- `pivote-1.html` a `pivote-6.html`: propuesta de indicadores y prototipo de dashboard por pivote.
- `final.html`: síntesis y hoja de ruta.
- `data.js`: set de datos simulado con fines académicos. `build.py` genera las páginas.
